Personal project · 2026 · deployed

AI Resume Intelligence Platform

A FastAPI service that ranks candidates for a role by combining classical and semantic retrieval, then explains each result with an LLM evaluation stage. Built end to end and deployed live.

  • Hybrid retrieval: dense embeddings (fastembed) + BM25 sparse search, fused with Reciprocal Rank Fusion, so ranking holds on both semantic and exact-keyword matches.
  • Benchmarked the retrieval path with a repeatable harness instead of estimating — measured, not guessed.
  • LLM evaluation stage (structured rubric via Instructor / Pydantic) returns why a candidate ranks where they do, not just a score.
